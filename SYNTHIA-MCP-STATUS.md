# MCP status

There is no active `MCP Hub` application/runtime in this checkpoint.

A preserved Autonomous-Agent donor contains a nested `diseminer-mcp-server`, but it is donor material rather than a mounted Synthia front-door capability.

MCP is not required for the VQ-VAE / ATO / Living Mesh runtime. If an MCP Hub is added later, it should be an interoperability surface rather than a replacement for Synthia's internal mesh messaging.
