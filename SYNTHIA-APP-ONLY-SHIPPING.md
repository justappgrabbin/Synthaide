# Synthia App-Only Shipping Rule

This package contains the current integrated Synthia/Acode application source and its executable tests.

It intentionally contains:

- no donor ZIP archives;
- no historical source ZIPs;
- no donor warehouse directory;
- no nested compressed archives used only for provenance.

Original donor archives must remain outside the application package.

Integrated source that the current app actually uses remains part of the app source tree.
