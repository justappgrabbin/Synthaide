This checkpoint distinguishes code that merely exists from components that are
mounted, addressed, tested, and reachable through the current runtime.

- Canonical state projection and ATO state-space kernel
- ATO macro/micro addressing and gate addressing
- Component identity registry and transition resolver
- Five-projection living semantic mesh and resonance relations
- Morph Chat, Morph Change Runtime, and Morph Substrate v0.6

## Body semantics added in v0.7

- The ceiling is 26 **simultaneously active action tools**, not 26 total
  components or 26 total potential capabilities.
- Mind, heart, directional, and social components remain addressable without
  consuming action-tool slots.
- A capability match is an invitation, not permission to execute.
- Every registered component must provide an agreement hook.
- Declining or unavailable components do not execute.
- Hands, browser, and network are host-bound effectors. One host's presence
  never implies another host is available.

## Donor disposition

The supplied donor applications were inspected as sources, not copied wholesale.
They contain complete Replit/Flask/React projects, generated UI layers,
dependencies, and repository histories that would enlarge and destabilize the
mobile application if grafted intact.

- Neural-Network-Builder: relevant neural/GNN concepts are already represented
  by the tested neural field and Human Design GNN runtime.
- Generative-Process-Cluster: its generative hierarchy is represented through
  the tested architecture modulation and experiment runtime.
- Conscious-Synth-AI and Causal-Canvas: retained as conceptual/reference donors;
  their server applications are not browser-native organs and were not falsely
  labeled as live mobile capabilities.
- FileHost and Flask: server-side hosting/build systems; these belong behind a
  remote retrieval interface, not inside the Android body.
- Foundry-Glyphs: registry, lineage, quality, and promotion UI/reference donor;
  it is not copied as a second application shell.
- `semantic_completion.js`, `vqvae.js`, and `sentence_realization.js`: their
  required behaviors are represented and covered by the current VQ-VAE and
  realization tests.

## Host effectors wired after the v0.7 checkpoint

The Acode/Cordova residence now binds four independent action tools to real
host interfaces:

- hands: scoped DOM click/focus through the live application document;
- browser: embedded Acode browser or Android external browser intent;
- network: Cordova native HTTP with browser fetch fallback;
- artifact retriever: binary fetch plus mandatory SHA-256 verification.

They remain sovereign and permission-bound. Hands require execution permission;
browser, network, and retrieval require network permission. Those permissions
remain off by default. Retrieval also declines unless a complete expected
SHA-256 digest is supplied.

## Addressed remote capability path wired in v0.9

The small-body path is now executable rather than a placeholder:

- Catalog records are indexed by canonical address, declared capability, and
  transition output.
- The on-device catalog persists in local Web Storage and hydrates on boot.
- Remote transition records are registered into Synthia's main Transition
  Resolver, so a requested state can locate a non-resident producer.
- Materialization retrieves through the independent host retriever, requires
  the catalog SHA-256 to match, runs Morph sandbox checks, and asks Morph
  whether to accept the candidate.
- A loaded module must identify itself and independently export both `agree()`
  and `execute()`; it still decides whether to participate in each actual task.
- Registration is inactive first. Expression alone consumes one action slot.
- The current resonance field is composed from goal, purpose, path,
  relationships, transits, channels, and other typed evidence. It may express
  a game, design, animation, browser action, or another actionable form.
- The field is allowed to remain sparse. Twenty-six is a maximum, not a target.
- A newly resonant tool does not enter a queue. The body deterministically
  recomposes from the strongest current evidence, and lower-resonance tools
  cease being expressed without being deleted from the system.

This makes the 26-slot ceiling a maximum simultaneous expression, not a ceiling
on the system's catalog or potential capabilities.

## Still host-dependent or not yet populated

The embodiment contract is present, but real effectors must be bound by the
host application at runtime:

- network and artifact retrieval still depend on a permitted Acode/Cordova host;
- the local catalog begins empty until trusted records are imported or synced;
- a Supabase catalog synchronization adapter and signed private-object URL
  provider are not yet connected;
- only verified single-file ESM modules are activatable; ZIP donors can be
  preserved and inspected but are not falsely treated as executable organs.

Until a host adapter reports both availability and permission, the relevant
component correctly declines. This prevents a visual hand or semantic browser
tool from being mistaken for an executable physical capability.

## Deferred intentionally

Remote module loading is now bounded and live. Self-building and self-promotion
remain deferred: Morph's sandbox, suggestion inbox, workboard-copy, immutable
original vault, and explicit acceptance boundary are the foundations, but no
component currently has unilateral authority to rewrite or promote Synthia.

## Verification boundary

All Synthia behavioral suites and the release audit pass. The APK packaging
script cannot complete in this source-only environment because the supplied
archive does not include executable `rspack` and `cordova` command binaries.
No APK claim is made for this checkpoint; it is an app-source checkpoint ready
for the established Android build environment.
