## Architecture

- Each executable Tool is an Automaton.
- Multiple sovereign Tool-Automatons connected by typed channels form Automata.
- The ATO Engine spawns and composes Automatons from addressed state-space mechanisms.
- Synthia's morphing interface is the user-facing expression layer; Acode is an on-demand computational environment beneath it.
- Interface morphing is an Expression and is recorded as a reversible addressed transition.
- Donor components qualify by computational value, human-cultivation value, or agent self-cultivation value.
