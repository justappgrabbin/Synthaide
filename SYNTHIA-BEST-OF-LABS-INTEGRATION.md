# Cynthia Best Of: Living Laboratory Integration

This additive revision keeps Morph and Synthia's state-space runtime authoritative. External projects enter as capabilities, experiments, or experience adapters; none becomes a second central brain.

## Executable native modules

- Biorhythm temporal-cycle calculator (experimental, explicitly non-predictive)
- Verified chemistry reaction state machine
- Codon evolution experiment using an Ornstein-Uhlenbeck selection process
- Normalized Human Design provider boundary for human-design-reader, Human Design LLM, and Eon

## Capability-only modules

- PanMig Chemistry Lab remains an optional Unity/3D build pack.
- Soul Codex contributes experience patterns only until its code license is verified.
- ElderMind remains reference-only because its published license requires written permission for product use.

All future provider outputs must pass through Morph preservation, classification, graphing, gap detection, interface inference, verification, and activation.
